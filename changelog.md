# Changelog

All notable changes to this template are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

While the template is on `0.x`, breaking changes may land in minor releases —
in particular whenever `ty` or Zensical, both still pre-1.0, change their APIs.

## [Unreleased]

## [0.4.0]

Complete rebuild of the template. The generated project shares almost nothing
with the previous version.

### Changed

- **Cookiecutter → [Copier](https://copier.readthedocs.io)**, so already
  generated projects can pull in template improvements with `copier update`.
- **The `main`, `typer` and `fastapi` branches collapse into a single
  `project_type` prompt** (`library` / `cli` / `api`).
- **Poetry → [uv](https://docs.astral.sh/uv)**, with PEP 621 metadata, PEP 735
  dependency groups, a committed `uv.lock` and the `uv_build` backend.
- **flake8 + black + isort → [Ruff](https://docs.astral.sh/ruff)**.
- **Material for MkDocs → [Zensical](https://zensical.org)**, with
  `mkdocstrings` for an autogenerated API reference.
- **Flat layout → `src/` layout**, with a `py.typed` marker.
- Generated files use lowercase names (`readme.md`), except those GitHub or
  tooling matches by exact name.
- Minimum Python is now 3.10; the previous template targeted 3.6, which reached
  end of life in December 2021.

### Added

- **PyPI publishing via
  [Trusted Publishing](https://docs.pypi.org/trusted-publishers/)** — OIDC, no
  secrets, with Sigstore attestations. The workflow refuses to publish when the
  git tag does not match the project version.
- **Type checking with [ty](https://github.com/astral-sh/ty)**, run
  non-blocking while it is pre-1.0.
- **[deptry](https://deptry.com)** for undeclared and unused dependencies.
- **[zizmor](https://github.com/zizmorcore/zizmor)** auditing the generated
  workflows, and OpenSSF Scorecard on this repository.
- Test matrix across Linux, macOS and Windows × every supported Python version.
- Task definitions in `pyproject.toml`, replacing the `Makefile`.
- pre-commit, `.editorconfig`, `SECURITY.md`, `AGENTS.md`, an optional
  multi-stage `Dockerfile` and an optional devcontainer.
- **A test suite for the template itself**, which previously had none. It
  renders every variant and runs the full toolchain inside each generated
  project, and verifies that `copier update` works.

### Fixed

- `github/codeql-action@v1`, retired by GitHub, so the old CodeQL workflow could
  no longer run at all. Now v4.
- `actions/checkout@v2`, `setup-python@v2` and `codecov-action@v1`, all
  obsolete. All actions are now pinned to full commit SHAs.
- The PyPI publish job, which was commented out and used a username and
  password pair.
- `dependabot.yml` targeted a `develop` branch that does not exist, and did not
  cover GitHub Actions.

### Removed

- `.deepsource.toml` — redundant now that Ruff and ty run in CI.
- `.coveragerc` and `Makefile` — folded into `pyproject.toml`.

### Migration

The Cookiecutter version is preserved, unmaintained, on the
`legacy/cookiecutter-main`, `legacy/cookiecutter-typer` and
`legacy/cookiecutter-fastapi` branches.
